# CCTS Package 1B — Theological and Missional Foundations

This package contains generator-ready Markdown source files for the Christian Community Transformation Society governance vault.

## Contents

- `source/02 Theology/Statement of Faith.md`
- `source/13 Strategy/Mission Statement.md`
- `source/13 Strategy/Vision Statement.md`
- `source/13 Strategy/Core Values.md`
- `source/00 Home/Governance Architecture.md`

## Use

Copy the `source/` folder into your Python content generator project, merging with the existing `source/` folder from Package 1A.

Then run:

```bash
python build.py
```

Edit files in `source/`, not in `dist/`.

## Package Scope

Package 1B adds the theological and missional foundation needed before constitution, governance framework, board, membership, and ministry policies.
