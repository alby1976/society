# Annual Cooperative Report

## Template Instructions

This template is used to prepare an annual report for a Society-affiliated worker cooperative, pilot cooperative, cooperative ministry, or national chapter cooperative program.

The report should summarize cooperative activity, worker development, finances, contracts, safety, risk, chaplaincy, church boundaries, mission alignment, lessons learned, decisions, and prayer needs.

The report should be preserved as part of institutional memory.
