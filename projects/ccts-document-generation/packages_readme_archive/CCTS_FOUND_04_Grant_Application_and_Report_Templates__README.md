## Metadata note

Following the updated YAML rule, `scriptural-foundation` and `confessional-foundation` fields are left blank in these operational templates because they do not directly depend on a specific Scripture passage or confessional article as their document foundation.

## Use

Copy the included `source/` folder into your Python content generator project, merging it with existing source files.

Then run:

```bash
python build.py
```

Edit source files only in `source/`, not in generated `dist/` output.
