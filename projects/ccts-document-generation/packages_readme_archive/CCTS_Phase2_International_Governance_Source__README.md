# CCTS Phase 2 — International Governance Source Package

This package contains generator-ready Markdown source files for the Christian Community Transformation Society rebuilt as an international society from Day One.

## How to use

1. Unzip this package.
2. Copy the `source/` folder into your Python content generator project.
3. Run `python build.py`.
4. Edit files only in `source/`; treat `dist/` as generated output.

## Scope

Phase 2 adds international foundations, theology, strategy, board governance, national chapter structure, ministry frameworks, institutional memory, and expansion documents.

## Important

These are governance drafts, not legal advice. Country-specific documents require review by qualified charity/nonprofit counsel in each jurisdiction.
