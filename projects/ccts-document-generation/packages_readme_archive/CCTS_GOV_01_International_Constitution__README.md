# CCTS GOV-01 — International Constitution

This generator-ready source package contains the first constitutional governance documents for the Christian Community Transformation Society.

## Contents

- `source/01 International Governance/International Constitution.md`
- `source/01 International Governance/International Constitution Commentary.md`

## Use

Copy the included `source/` folder into your Python content generator project, merging it with existing source files from Foundation-01 and Foundation-02.

Then run:

```bash
python build.py
```

Edit source files only in `source/`, not in generated `dist/` output.
