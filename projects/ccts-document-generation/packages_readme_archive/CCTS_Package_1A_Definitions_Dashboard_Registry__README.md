# CCTS Package 1A — Definitions, Home Dashboard, Document Registry

This package contains generator-ready Markdown source files for the Christian Community Transformation Society governance vault.

## Contents

- `source/00 Home/Home Dashboard.md`
- `source/00 Home/Document Registry.md`
- `source/01 International Governance/Definitions of Key Terms.md`

## Use

Copy the `source/` folder into your Python content generator project.

Then run:

```bash
python build.py
```

These files are designed to be source files, not generated output. Edit these files in `source/`, not in `dist/`.

## Package Scope

This is Package 1A. It intentionally contains a small complete increment rather than pretending the entire governance vault is finished.
