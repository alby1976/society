# Annual Housing Report

## Template Instructions

This template is used to prepare an annual housing report for a Society housing ministry, housing trust, national chapter housing program, or affiliated housing entity.

The report should summarize housing activity, resident support, affordability, finances, maintenance, risks, church connection, chaplaincy, mission alignment, decisions, and prayer needs.

The report should be preserved as part of institutional memory.
