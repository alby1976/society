# Master Document Registry

## 1. Purpose

This register is the master index of governance documents generated for the Christian Community Transformation Society governance vault.

It should become the single source for document IDs, titles, status, categories, and review responsibility.

---

# 2. Registry Rules

1. Every official document should have a stable `document-id`.
2. Every document should have YAML frontmatter.
3. `scriptural-foundation` and `confessional-foundation` should be populated only when those references directly provide the foundation for that specific document.
4. Draft documents should remain marked `Draft` until approved.
5. Superseded documents should not be deleted without archive record.
6. Registry updates should be preserved as institutional memory.
7. Generated output should not be treated as source of truth.
