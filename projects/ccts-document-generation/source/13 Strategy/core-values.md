# Core Values

## Adopted Values

- Faithfulness to Scripture.
- Confessional Reformed identity.
- Service to the local church.
- Prayerful dependence on God.
- Mercy joined to discipleship.
- Stewardship of resources and institutions.
- Accountability and transparency.
- Long-term institutional memory.
- Community transformation through ordinary Christian faithfulness.

## Key Decisions

- Values must be embedded into governance, not merely stated in promotional language.
- Values must shape board decisions, ministry approval, reporting, partnerships, and succession.
