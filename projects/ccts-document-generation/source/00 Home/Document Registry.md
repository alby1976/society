# Document Registry

## Purpose

The Document Registry is the master inventory of governance documents for the Christian Community Transformation Society. It supports version control, review scheduling, dependency tracking, document ownership, and long-term institutional memory.

This register should be generated or updated from Markdown frontmatter whenever possible.

---

# Registry Standards

Each document should include:

- `document-id`
- `title`
- `version`
- `status`
- `type`
- `document-category`

# Status Values

| Status | Meaning |
|---|---|
| Draft | Under development and not yet approved |
| Proposed | Ready for formal review |
| Active | Approved and currently governing |
| Archived | Retained for history but no longer governing |
| Superseded | Replaced by another document |
| Retired | No longer used and not replaced |

---

# Type Values

| Type | Meaning |
|---|---|
| Constitution | Supreme internal governing document |
| Bylaw | Legal governance rule |
| Policy | Binding governance rule |
| Framework | Structured governance model |
| Charter | Establishes a board, council, committee, or body |
| Manual | Collected operational or governance guidance |
| Procedure | Step-by-step implementation document |
| Template | Reusable form or format |
| Register | Official list or record |
| Index | Navigation document |
| Reference | Glossary or explanatory reference |

---

# Priority Values

| Priority | Meaning |
|---|---|
| Critical | Needed before incorporation, launch, or formal governance |
| High | Needed for early operations |
| Medium | Needed for maturity and consistency |
| Low | Useful but not urgent |

# Maintenance Rules

1. No document should be treated as Active unless it has an approving authority.
2. No international document should be approved without review for consistency with [[Definitions of Key Terms]].
3. National chapter documents should identify their international parent document when applicable.
4. Superseded documents should remain accessible for institutional memory.
5. Every major decision changing a document should be recorded in [[Decision Register]].
