# Package Inventory and Merge Order

## 1. Purpose

This register lists generated governance vault packages and recommends the order for merging them into the main generator repository.

---

# 2. Merge Principle

Merge foundational packages first, then governance packages, then ministry packages, then controls, then registry/audit/release packages.

This makes link review easier and reduces confusion.
