# Institutional Memory System

## Executive Summary

The Institutional Memory System preserves the Society's theology, decisions, documents, reports, lessons learned, and governance history so that the mission remains stable after founding leaders are no longer active.

## Components

- Living Obsidian governance vault.
- Decision Register.
- Document Registry.
- Changelog.
- Release Plan.
- Stewardship Advisors.
- Historical archive.
- Governance handbook.

## Adopted Principles

- Memory must be intentional, searchable, versioned, and reviewable.
- Important decisions should record reasons, alternatives, and related documents.
- Former leaders may advise, but they do not govern.
- The vault is the Society's primary knowledge repository.

## Key Decisions

- Obsidian is the primary living governance repository.
- Institutional memory should be embedded into reports, minutes, decisions, and document updates.
