# Board Legal and Theological Review Package Procedure

## 1. Purpose

This procedure explains how to prepare review packages for board, legal, theological, church advisory, finance, safeguarding, or public review.

---

# 2. Governing Principle

Reviewers should receive the documents they need, the context they need, and clear instructions about what kind of review is being requested.

Do not send the entire vault to every reviewer if a focused package will do.

---

# 3. Review Package Types

| Package | Main Review Question |
|---|---|
| Board Review | Can this be governed, approved, delegated, and implemented? |
| Legal Review | Is this lawful, risky, incomplete, or needing revision? |
| Theological Review | Is this faithful to Scripture and adopted confessional identity? |
| Church Advisory Review | Does this support faithful local churches without replacing them? |
| Finance Review | Are funds, restrictions, budgets, and reporting properly handled? |
| Safeguarding Review | Are people protected and concerns escalated properly? |
| Public Review | Is this suitable for public release? |

---

# 4. Package Preparation Steps

1. Select package configuration.
2. Build current source.
3. Review build report.
4. Confirm confidentiality.
5. Generate package.
6. Review package index.
7. Add review instructions.
8. Send to reviewer or store for board packet.
9. Record package in changelog if release-level.
10. Record decisions after review.

---

# 5. Board Review Package

Include documents related to:

- authority;
- reserved powers;
- board structure;
- membership;
- mission alignment;
- reporting;
- finance;
- risk;
- HR;
- safeguarding;
- communications;
- release plan.

Board reviewers should identify:

- decisions required;
- documents ready for approval;
- documents needing legal review;
- documents needing theological review;
- documents needing revision;
- implementation risks.

---

# 6. Legal Review Package

Include documents related to:

- constitution;
- chapter formation;
- legal readiness;
- finance;
- HR;
- safeguarding;
- privacy;
- housing;
- grants;
- cooperative;
- fundraising;
- public communications.

Legal reviewers should identify:

- legal risks;
- required jurisdiction-specific changes;
- prohibited actions;
- missing filings;
- document language needing revision;
- matters needing specialist review.

---

# 7. Theological Review Package

Include documents related to:

- statement of faith;
- mission and vision;
- core values;
- theological oversight;
- church advisory;
- chaplaincy;
- spiritual care;
- prayer;
- church referral;
- seminary recognition.

Theological reviewers should identify:

- doctrinal concerns;
- church boundary concerns;
- confessional consistency;
- language needing clarification;
- inappropriate claims of church authority;
- matters needing church advisory review.

---

# 8. Review Instructions

Each package should include:

- purpose;
- what is included;
- what is not included;
- review questions;
- deadline if applicable;
- how to provide feedback;
- confidentiality note;
- source-of-truth note.

---

# 9. Feedback Handling

Feedback should be recorded as:

- accepted;
- accepted with modification;
- deferred;
- rejected with rationale;
- needs further review.

Significant feedback should result in:

- decision register update;
- document revision;
- changelog update;
- risk register update if needed;
- legal issue register update if needed.

---

# 10. Review

This procedure should be reviewed after each major review cycle.
