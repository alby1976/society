# Master Changelog

## 1. Purpose

This changelog preserves major changes to the governance vault.

It should help future leaders understand what changed, when it changed, why it changed, and which package introduced it.

---

# 2. Changelog Rules

1. Record package-level changes.
2. Record major document additions.
3. Record renames, supersessions, or removals.
4. Record changes to YAML standards.
5. Record changes to scriptural or confessional foundation rules.
6. Record release milestones.
7. Keep entries concise but useful.
